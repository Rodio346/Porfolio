# Vishal Yadav Portfolio

Live site: [https://rodio346.github.io/Portfolio/](https://rodio346.github.io/Portfolio/)

## Run locally

- `npm install`
- `npm run dev`
- open `http://localhost:4321/Portfolio/`
- professional route: `http://localhost:4321/Portfolio/professional/`
- personal route: `http://localhost:4321/Portfolio/about-me/`

## Build

- `npm run build`
